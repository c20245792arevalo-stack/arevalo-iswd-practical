# Cyn Hair & Beauty Studio

**Live site:** https://github.com/c20245792arevalo-stack/arevalo-iswd-practical.git

## About

Cyn Hair & Beauty Studio is a neighborhood salon website for Victorias City offering haircuts, color, treatments, and nail care with transparent pricing and easy booking.

## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |
|---|---|---|---|
| Dominant | 60% | `#BE185D` (Light) / `#000000` (Dark) | Page background |
| Secondary | 30% | `#2A1650` (Plum) / `#0D0D0D` (Panel) | Cards, sections, navigation |
| Accent | 10% | `#FDE047` (Gold) / `#F472B6` (Pink) | Buttons, links, highlights |

### Visual style

**Style chosen:**Glass Morphism, Minimalist with Bento Grid

**Why I chose it:**I combined soft glassmorphism(frosted backdrop blurs) with clean typography and spacious layouts with structured bento grid elements to showcase modern salon services and imagery cleanly.

### Contrast check

Body text color vs. background color: `#E4E4E7` (zinc-200) on `#000000` (Dark mode) / `#2A1650` on `#FFFFFF` (Light cards)
Contrast ratio: > 7:1 (Exceeds WCAG AA standard of 4.5:1)
Tool used: WebAIM Contrast Checker

## Features

- [x] Mobile-first responsive layout
- [x] Dark mode toggle
- [x] Page-load intro animation (GSAP timeline)
- [x] Scroll reveals on every section below the hero (ScrollTrigger)
